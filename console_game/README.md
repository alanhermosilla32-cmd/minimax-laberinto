# 🎮 Juego de Laberinto en Consola: Ratón vs Gato

¡Bienvenido al desafío del laberinto! Eres un ratón valiente en busca de queso, pero cuidado... ¡hay un gato hambriento acechando!

## 📜 Descripción
Este es un juego sencillo de consola programado en Python. Tu objetivo es guiar al ratón (`🐭`) a través del laberinto hasta encontrar el queso (`🧀`) antes de que el gato (`🐱`) te atrape.

## 🕹️ Controles
Usa las teclas para moverte:
- **W**: Arriba
- **S**: Abajo
- **A**: Izquierda
- **D**: Derecha
- **Q**: Salir del juego

## 🚀 Cómo Jugar
1.  Abre una terminal o símbolo del sistema.
2.  Navega a la carpeta del juego:
    ```bash
    cd "c:\Users\alan.hermosilla\Desktop\LABERINTO MINIMAX\console_game"
    ```
3.  Ejecuta el juego con Python:
    ```bash
    python juego.py
    ```
4.  ¡Diviértete!

## 🛠️ Requisitos
- Python 3.x instalado en tu sistema.
- Una terminal compatible con emojis (Windows Terminal, PowerShell, CMD moderno).

## 📝 Notas
- El gato se mueve cada vez que tú te mueves.
- ¡Piensa bien tus movimientos!
